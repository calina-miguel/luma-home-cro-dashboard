# Luma Home Goods CRO Dashboard

Interactive ecommerce experiment dashboard for Luma Home Goods, covering hypothesis tracking, conversion lift, revenue impact, and rollout decisions.

Production: https://luma-home-cro-dashboard.vercel.app

## Scope

- Experiment hypothesis framing
- Conversion lift calculations
- Revenue impact modeling
- Rollout decision dashboard patterns

## Stack

- HTML, CSS, JavaScript
- Vercel hosting

## Local Operations

```bash
npm run start
```

The CRO dashboard is served as a static experiment interface and can be deployed directly through Vercel.
