# Luma Home Goods CRO Dashboard Specification

## Interface Direction

Luma Home Goods uses a conversion dashboard for ecommerce experiment planning and rollout decisions. The interface should make winner status, lift, revenue impact, and traffic allocation easy to scan without hiding the underlying hypothesis.

## Core Screens

- Experiment summary metric cards
- Product-page CTA hypothesis panel
- Traffic allocation control
- Conversion comparison chart

## Implementation Notes

- Preserve native range input behavior.
- Keep calculations transparent and stable during interaction.
- Maintain Vercel compatibility with static deployment output.
- Keep repository language operational and organization-facing.
