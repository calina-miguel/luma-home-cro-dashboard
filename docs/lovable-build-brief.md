# Luma Home Goods CRO Dashboard

Build a conversion rate optimization dashboard for Luma Home Goods, an ecommerce home goods brand managing product-page experiments. The interface should summarize experiment hypotheses, conversion lift, revenue impact, traffic allocation, and rollout decisions.

Use a responsive React front-end suitable for Vercel deployment. The first screen should show the Luma Home Goods CRO dashboard title, winning variant, conversion lift, projected monthly impact, and the active product-page CTA experiment.

Required features:

- Metric summary cards for winning variant, conversion lift, projected monthly impact, and confidence.
- Product page CTA test panel with hypothesis, control copy, variant copy, and decision status.
- Interactive traffic allocation slider for Variant B.
- Dynamic conversion rate, lift, and projected revenue calculations.
- Conversion comparison chart for Control and Variant B.
- Experiment notes area covering learnings, rollout criteria, and follow-up checks.
- Responsive layout for mobile and desktop.
- Accessible controls with visible focus states and semantic structure.

Visual direction:

- Quiet ecommerce analytics interface.
- Light neutral background, white panels, deep ink text, teal metrics, and restrained amber decision accents.
- Operational dashboard style, not a landing page.
- Cards only for metrics and experiment modules, with modest radius and clean spacing.
